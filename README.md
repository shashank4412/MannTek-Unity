## Instructions

### Placing and Playing Animation
1. Install the app on your iOS device and allow camera permissions.
2. Scan the floor surface for 10–20 seconds (slightly rotate the device to help detect surfaces).
3. Tap the button to open the model gallery and select the first model: **Manntek Coupling**.
4. Tap anywhere on the scanned surface to spawn the model at that location.
5. Use the **Animate** button to toggle between coupling and decoupling animations.

### Operating the Model
1. Select the model by tapping on it (it will turn violet when selected).
2. Once selected, you can:
   - Delete
   - Scale
   - Rotate
   - Move the model
